# Research Paper Mastery (Claude / Agent Skill)

Veteran-level expertise for planning, writing, revising, and publishing academic research papers, modeled on a senior scholar with five decades of authoring, peer-reviewing, and editorial experience.

---

## 🎯 What This Skill Does

This skill provides end-to-end guidance for academic manuscripts and scientific papers across STEM, medicine, social sciences, computer science & machine learning, engineering, mathematics, and humanities.

It covers:
- **Paper Planning & Positioning**: Formulating novel contributions, journal/conference scoping, authorship.
- **Section-by-Section Craft**: Title, abstract, introduction, methods, results, discussion, and conclusion.
- **Rigor & Statistics**: Study design, statistical reporting, reproducibility, and avoiding p-hacking.
- **Visuals & Tables**: Figures, captions, and data presentation.
- **Literature Review & Citations**: Literature synthesis, search strategies, and reference integrity.
- **Submission & Peer Review**: Journal selection, editor cover letters, rebuttal letters, and handling revisions/rejections.
- **Ethics & Integrity**: Authorship ethics, plagiarism, preprint policies, and AI disclosure transparency.
- **Prose & Style**: Sentence-level clarity, scientific tone, and academic writing polish.
- **Discipline Variants**: Nuanced conventions for biomedical, CS/ML, math, engineering, social sciences, and humanities.
- **Checklists & Rubrics**: Pre-submission review rubrics and manuscript linting tools.
- **Templates**: Ready-to-use cover letters, abstract formulas, rebuttal responses, and outlines.

## 🚀 How to Install and Use

### For Claude / Claude Code
Clone or copy this repository into your Claude configuration or skills directory:
```bash
git clone https://github.com/TANMAY-KARTIKAY/research-paper-mastery.git
```
In Claude Code, you can add it to your project skills folder or global skills directory.

### For Antigravity / Agentic Coding Assistants
Place this folder in your workspace `.agents/skills/` directory:
```bash
mkdir -p .agents/skills/
git clone https://github.com/TANMAY-KARTIKAY/research-paper-mastery.git .agents/skills/research-paper-mastery
```
The agent will automatically discover the skill and load relevant sections on demand when you work on academic papers.
